# Scratch Maze Game 🎮

I made this cool maze game in Scratch! its a maze where you have to get to the end without touching the walls.

you can play it here: https://scratch.mit.edu

i dont have the link to my exact project anymore but trust me it was awesome lol. the character was a cat and the walls were red.

## how it worked
- arrow keys to move
- if you touch the wall you go back to start
- there was a timer to see how fast you could finish
- i made 3 levels!!
