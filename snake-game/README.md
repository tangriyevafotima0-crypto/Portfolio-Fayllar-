# Snake Game

Classic snake game built with Pygame. Eat food to grow and increase your score. The game speeds up as your score gets higher!

## Setup

```bash
pip install -r requirements.txt
python snake.py
```

## Controls

- **Arrow Keys** - Move the snake (Up, Down, Left, Right)
- **Space** - Restart after game over
- **ESC** - Quit the game

## Features

- Score tracking on screen
- Speed increases as you score more points
- Game over screen with restart option
- Snake cannot reverse direction
- Food never spawns on the snake body
