# Password Generator

A password generator with a graphical interface. Customize the length and character types, then generate secure random passwords.

## How to Run

```bash
python generator.py
```

No extra dependencies - uses Python's built-in Tkinter and random libraries.

## Features

- Adjustable password length (8-32 characters)
- Toggle character types: uppercase, lowercase, numbers, symbols
- Password strength indicator (Weak/Medium/Strong)
- Copy to clipboard with one click
- Clean and simple GUI
