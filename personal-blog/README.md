# Personal Blog

A responsive personal blog built with HTML, CSS, and JavaScript. Features dark mode toggle and clean layout.

## How to View

Open `index.html` in any modern web browser.

## Features

- Responsive design that works on desktop and mobile
- Dark mode toggle (preference saved to localStorage)
- CSS Grid layout for post cards
- Custom fonts via Google Fonts
- Smooth hover effects and transitions
- Blog post pages with clean typography

## Pages

- `index.html` - Home page with post listing
- `post1.html` - Blog post about learning Python
- `post2.html` - Blog post about building GUI apps
