Building My First GUI App

December 3, 2024

After months of writing command-line programs, I wanted to make something with actual buttons and windows. That is when I discovered Tkinter.

What is Tkinter?

Tkinter is Python's built-in library for creating graphical user interfaces. It comes pre-installed with Python, so you do not need to install anything extra. That made it perfect for a beginner like me.

The To-Do App

I decided to build a to-do list app because it seemed simple enough but still useful. I wanted it to have:

  • An entry field to type new tasks
  • A list showing all tasks
  • Buttons to add, delete, and mark tasks as done
  • Saving tasks to a file so they persist

Challenges

The hardest part was learning how GUI layouts work. Unlike print statements that just go line by line, you have to think about where each widget goes on the screen. Frames, packing, and grid layouts took some getting used to.

Another challenge was connecting the GUI to the logic. When someone clicks a button, what should happen? Event-driven programming was a new concept for me.

The Result

After a few days of work, I had a working to-do app! It is not the prettiest thing in the world, but it works and I am proud of it. Next I want to try building a game with Pygame.
