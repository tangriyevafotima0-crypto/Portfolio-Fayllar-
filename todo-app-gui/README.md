# To-Do App (GUI)

A simple to-do list application with a graphical interface built using Tkinter.

## How to Run

```bash
python todo.py
```

No extra dependencies needed - uses Python's built-in Tkinter library.

## Features

- Add new tasks with the entry field or press Enter
- Mark tasks as complete (shown in green with [DONE] prefix)
- Delete individual tasks
- Clear all completed tasks at once
- Tasks are saved to `tasks.json` automatically
- Tasks persist between sessions
